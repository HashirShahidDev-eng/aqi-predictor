# Lahore AQI Predictor
A Data Science Internship Project at **10Pearls** that predicts the Air Quality Index (AQI) of Lahore for the next **24, 48, and 72 hours**.

**Features**
* Collects air quality and weather data from **Open-Meteo**.
* Uses **XGBoost** to predict future AQI.
* Uses **Hopsworks** for data and model management.
* Uses **GitHub Actions** for automation.
* Displays predictions through a **Streamlit dashboard**.

## Technologies
Python, XGBoost, Hopsworks, GitHub Actions, Streamlit, Open-Meteo, and SHAP.
